# Expo 프로젝트 생성하기

## cmd
1. expo 설치
```
npm install expo-cli
```

2. myApp 폴더 생성 (template = blank)
```
expo init myApp
```

3. myApp 폴더로 이동 (VS Code로 바로 열어도 됨)
```
cd myApp
```

4. VS Code 실행
```
code .
```

## VS Code
1. App.js 코드 작성
2. 터미널 -> cmd 선택
3. ```npm start``` 입력

## 가상 스마트폰 Expo 앱 설치
npm start 후 a 키 누르기

## expo 캐시 제거 후 시작
```
npx expo start -c
```
